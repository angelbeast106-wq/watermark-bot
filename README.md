# Telegram watermark bot

Бот принимает изображение, накладывает логотип канала как водяной знак, позволяет сдвигать водяной знак влево/вправо и зеркалить само изображение.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте конфиг:

```bash
cp .env.example .env
```

3. Вставьте токен в `.env`.
4. Положите логотип канала в `assets/watermark.png`.
   Лучше использовать PNG с прозрачным фоном.
5. Установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

6. Запустите:

```bash
python bot.py
```

## Параметры `.env`

- `WATERMARK_ANCHOR` - базовая позиция водяного знака: по умолчанию `top_right`; также доступны `top_left`, `bottom_right`, `bottom_left`, `center` и другие из `.env.example`.
- `WATERMARK_WIDTH_PERCENT` - ширина логотипа в процентах от ширины изображения.
- `WATERMARK_MARGIN_PERCENT` - общий отступ от края в процентах от меньшей стороны изображения; сейчас `6`, чтобы логотип был чуть левее правого края.
- `WATERMARK_TOP_MARGIN_PERCENT` - отдельный отступ сверху; `0` прижимает логотип к верхнему краю.
- `WATERMARK_OPACITY` - прозрачность от `0` до `1`; `1` наносит логотип без дополнительной прозрачности.
- `SHIFT_STEP_PX` - на сколько пикселей сдвигается водяной знак при нажатии кнопки.

## Использование

Отправьте боту фото или изображение файлом. Бот пришлет превью с кнопками:

- `←` и `→` сдвигают водяной знак.
- `Зеркалить` отражает само изображение по горизонтали.
- `Сброс` возвращает исходные настройки.
- `Готово` отправляет результат файлом `watermarked.jpg`.
